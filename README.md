# StickBrief legal pages

Public HTTPS home for TikTok developer app `n8n_forTiktok`.

Not a consumer product. GitHub Pages only so App details can store:

- Web/Desktop URL → `/`
- Privacy Policy URL → `/privacy.html`
- Terms of Service URL → `/terms.html`

Do not invent a second domain. After Pages is live, paste those three URLs into the TikTok portal, then **URL properties → Verify**. Put TikTok’s signature file in this folder if verification is by URL prefix.
